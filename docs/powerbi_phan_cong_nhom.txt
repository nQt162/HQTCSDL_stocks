Du an: Stock Prediction System / ClickHouse / Machine Learning / Streamlit / Power BI

Muc tieu cua file Power BI
==========================
Power BI trong du an nay khong chi de bao cao Model 4.
Power BI dung de trinh bay TOAN BO HE THONG:

1. Du lieu co phieu va qua trinh xu ly du lieu.
2. ClickHouse la kho du lieu trung tam.
3. Cac bang mart duoc tao san de phuc vu dashboard.
4. Ket qua cua cac model:
   - Model 1: du bao gia / expected return.
   - Model 2: du doan future return.
   - Model 3: sinh tin hieu giao dich BUY / HOLD / SELL.
   - Model 4: du doan outperform benchmark.
   - Model 5: canh bao rui ro co phieu.
5. Trang tong hop de so sanh vai tro cua cac model.

Thong diep khi bao cao voi thay/co:
- Streamlit la web demo tuong tac voi model.
- ClickHouse la database luu du lieu va bang mart.
- Power BI la lop bao cao BI, giup loc, xem dashboard, xuat PDF/PPT.


VAI TRO CUA BAN TRUOC KHI CHIA VIEC
===================================

1. Chon cac bang can dung trong Navigator.

5. Luu thanh file mau:
   powerbi_template.pbix

- Khong chup man hinh file .env.
- Neu thanh vien khac khong ket noi duoc database, ban co the gop file giup ho thay vi gui password cong khai.

CAC MEASURE DUNG CHUNG NEN TAO
==============================
Vao Modeling -> New measure.
Neu Power BI bao loi do ten bang/cot khong ton tai, bo qua measure do hoac sua lai ten bang dung voi Fields cua ban.

1. Dem so dong features
-----------------------
Feature Rows =
COUNTROWS(features_all)


2. So ma co phieu
-----------------
Symbol Count =
DISTINCTCOUNT(features_all[symbol])


3. So ngay giao dich
--------------------
Trading Day Count =
DISTINCTCOUNT(features_all[trading_date])


4. Gia dong cua trung binh
--------------------------
Average Close =
AVERAGE(features_all[close])


5. Model 4 - tong so du doan
----------------------------
M4 Total Predictions =
COUNTROWS(mart_model4_benchmark_outperformance)


6. Model 4 - so du doan dung
----------------------------
M4 Correct Predictions =
SUM(mart_model4_benchmark_outperformance[prediction_correct])


7. Model 4 - accuracy
---------------------
M4 Accuracy % =
DIVIDE([M4 Correct Predictions], [M4 Total Predictions])


8. Model 4 - xac suat outperform trung binh
-------------------------------------------
M4 Avg Outperform Probability =
AVERAGE(mart_model4_benchmark_outperformance[outperform_probability])


9. Model 5 - xac suat rui ro trung binh
---------------------------------------
M5 Avg Risk Probability =
AVERAGE(mart_model5_risk_predictions[risk_probability])


10. Model 5 - so canh bao high risk
-----------------------------------
M5 High Risk Count =
COUNTROWS(
    FILTER(
        mart_model5_risk_predictions,
        mart_model5_risk_predictions[risk_label] = "HIGH_RISK"
    )
)


Luu y format:
- Cac measure co dau % nen format la Percentage.
- Cac gia tri probability cung nen format Percentage.
- Cac gia tri tien/gia co phieu nen format Number, co dau phan tach hang nghin.

CAU TRA LOI KHI THAY/CO HOI
===========================
1. "Tai sao da co Streamlit con lam Power BI?"
Tra loi:
"Streamlit dung de demo ung dung va model prediction. Power BI dung de bao cao BI, xem tong quan, loc du lieu, chia page theo model va xuat PDF/PPT cho nguoi dung khong can chay code."

2. "Power BI co ket noi truc tiep database khong?"
Tra loi:
"Co. Power BI ket noi ClickHouse thong qua connector/ODBC. Cac bang mart trong ClickHouse duoc dung lam nguon du lieu cho dashboard."

3. "Vi sao chia nhieu model?"
Tra loi:
"Moi model giai quyet mot bai toan khac nhau: du bao gia, du doan return, sinh tin hieu giao dich, du doan outperform benchmark va canh bao rui ro. Power BI giup dat cac ket qua nay vao cung mot bao cao tong hop."

4. "Diem manh cua thiet ke du lieu la gi?"
Tra loi:
"Du lieu duoc tach theo pipeline: raw/clean/features/mart/audit. Cac bang mart da tong hop san nen Power BI chi can doc va truc quan hoa, khong phai xu ly logic phuc tap trong dashboard."
